# 상용 공기청정기 및 이동형 공기정화 로봇 비교 기반 프로젝트 차별성 보고서 초안

## 1. 보고서 목적

본 보고서는 현재 진행 중인 **TurtleBot3 기반 자율 공기정화 로봇 프로젝트**의 차별성을 명확히 설명하기 위해 작성되었다. 기존 상용 공기청정기와 이동형 공기정화 로봇의 기능을 조사하고, 본 프로젝트가 어떤 부분에서 다른 기술적 가치를 가질 수 있는지 정리한다.

현재 프로젝트는 단순히 공기청정기를 로봇에 탑재하는 것을 목표로 하지 않는다. 로봇이 실내 공간을 이동하며 PM2.5 데이터를 수집하고, 지도 위에 공기질 분포를 시각화하며, 고농도 구역을 우선적으로 정화하는 **디지털 트윈 기반 자율 공기질 관리 시스템**으로 확장하는 것을 목표로 한다.

## 2. 기존 상용 제품 조사

### 2.1 고정형 스마트 공기청정기

대표적인 고정형 스마트 공기청정기에는 삼성 SmartThings 연동 공기청정기와 LG PuriCare 360 계열 제품이 있다.

삼성 공기청정기는 SmartThings 앱을 통해 전원 제어, 풍량 조절, 필터 상태 확인, 실내 공기질 모니터링을 제공한다. 삼성 공식 지원 문서에 따르면 SmartThings 앱에서는 실내 PM10, PM2.5, PM1.0 및 가스 청정도 등을 확인할 수 있다. 또한 실외 공기질도 앱에서 확인할 수 있다.

LG PuriCare 360은 360도 흡입/정화 구조, HEPA 필터, PM 1.0 센서, ThinQ 앱 연동, 자동 운전 기능을 제공한다. LG 공식 제품 설명에 따르면 ThinQ 앱으로 공기청정기를 원격 제어하고, 공기질과 필터 상태를 확인할 수 있다. 또한 PM 1.0 센서가 입자를 감지하고, Auto Mode에서 공기 상태 변화에 따라 동작을 조절한다.

이러한 제품들은 센서 기반 자동 운전과 앱 기반 모니터링이 강점이다. 그러나 기본적으로 한 위치에 고정되어 있기 때문에, 실내 여러 지점의 공기질 차이를 직접 측정하거나 오염 지점으로 이동해 정화하는 기능은 제한적이다.

### 2.2 개인 추적형 공기청정기

Dreame AirPursue PM20과 같은 최신 스마트 공기청정기는 레이더 또는 인체 감지 기능을 이용해 사용자의 위치를 추적하고, 사용자가 있는 방향으로 정화된 공기를 보내는 기능을 제공한다. 공식 제품 설명과 리뷰에 따르면 AirPursue PM20은 Auto Mode에서 사용자의 위치에 따라 바람 방향을 조절하고, 여러 명이 있을 경우 양쪽으로 풍향을 전환하는 기능을 제공한다.

이러한 제품은 기존 고정형 공기청정기보다 능동적인 사용자 중심 제어가 가능하다는 장점이 있다. 그러나 장치 자체가 실내 공간을 이동하는 것은 아니며, 오염 지점을 지도화하거나 로봇이 직접 고농도 구역으로 이동하는 구조는 아니다. 즉, 사람 중심의 풍향 제어에는 강점이 있지만, 공간 전체의 오염 분포를 탐색하고 정화 우선순위를 결정하는 시스템은 아니다.

### 2.3 이동형 공기정화 로봇

SOTO-RA와 같은 의료용 공기정화 로봇은 자율주행 기능과 공기 정화/살균 기능을 결합한 상용 제품이다. 공식 설명에 따르면 SOTO-RA는 자율 내비게이션 기능을 갖추고 다양한 실내 환경에서 이동형 공기 정화 및 살균을 수행한다. 또한 SLAM 기반 지도 작성, 장애물 회피, 충전 복귀, 지도 기반 정화 모드 등을 제공한다.

CDaBot과 같은 상업용 이동형 공기정화 장치도 대형 실내 공간에서 공기질 관리를 목적으로 한다. 이러한 제품들은 고정형 공기청정기의 커버리지 한계를 보완하고, 넓은 공간에서 이동하면서 공기 정화를 수행한다는 점에서 본 프로젝트와 유사한 문제의식을 가진다.

다만 상용 이동형 공기정화 로봇은 제품 완성도와 정화 성능은 높지만, 사용자가 내부 의사결정 과정을 확인하거나, 측정된 공기질 데이터를 지도 위에서 학습/실험 목적으로 분석하는 기능은 제한적으로 공개되어 있다. 또한 대부분 의료/상업용 제품으로, 교육용 ROS 2 로봇 플랫폼에서 알고리즘과 관제 구조를 직접 설계하고 검증하는 프로젝트와는 목적이 다르다.

## 3. 기존 제품의 공통 한계

조사한 제품들을 종합하면 다음과 같은 한계가 있다.

첫째, 고정형 공기청정기는 특정 위치의 공기질을 측정하고 정화할 수 있지만, 실내 공간 전체의 위치별 오염 분포를 직접 측정하기 어렵다.

둘째, 스마트폰 앱에서 공기질 수치를 보여주더라도, 대부분은 현재 위치 또는 장치 주변의 공기질 정보에 가깝다. 실내 지도 위에 오염 분포를 누적하고, 로봇 위치와 연결해 보여주는 디지털 트윈 형태는 일반적이지 않다.

셋째, 개인 추적형 공기청정기는 사용자를 향해 바람을 보내는 기능은 강하지만, 오염원이 어디에 있는지 탐색하거나 고농도 구역을 우선 정화하는 구조는 아니다.

넷째, 이동형 공기정화 로봇은 자율주행과 정화 기능을 제공하지만, 내부 알고리즘이 상용 제품 내부에 포함되어 있어 교육/연구 목적으로 공기질 지도 생성, 경로 선택, 정화 우선순위 계산 과정을 직접 구현하고 설명하기 어렵다.

## 4. 본 프로젝트의 차별화 방향

본 프로젝트의 차별성은 다음과 같이 정리할 수 있다.

> 본 프로젝트는 단순 이동형 공기청정기가 아니라, 로봇이 수집한 PM2.5 데이터를 실내 지도와 결합하여 공기질 디지털 트윈을 생성하고, 고농도 구역을 우선적으로 정화하는 ROS 2 기반 자율 공기질 관리 시스템이다.

핵심 차별화 요소는 다음 세 가지이다.

1. **실시간 공기질 Heatmap 기반 디지털 트윈 지도**
2. **Utility 기반 고농도 구역 우선 정화 알고리즘**
3. **정화 전후 PM2.5 변화 시각화**

## 5. 차별화 기능 1: 실시간 공기질 Heatmap 기반 디지털 트윈 지도

기존 웹 지도는 ROS 점유격자 지도 형태로 로봇의 위치와 공간 구조를 보여주는 데 초점이 있다. 향후 개선 방향은 이 지도 위에 PM2.5 데이터를 겹쳐 표시하여, 실내 공간의 공기질 상태를 한눈에 볼 수 있는 Heatmap을 구현하는 것이다.

로봇이 이동하면서 수집하는 데이터는 다음 형태로 저장할 수 있다.

```text
(x 좌표, y 좌표, PM2.5 농도, 측정 시간)
```

웹 대시보드는 이 데이터를 기반으로 지도 위에 측정점과 Heatmap을 표시한다. PM2.5가 낮은 구역은 파랑 또는 초록, 높은 구역은 주황 또는 빨강으로 표시한다. 측정하지 않은 구역은 주변 측정값을 바탕으로 거리 기반 보간(IDW, Inverse Distance Weighting)을 적용하여 부드러운 오염 분포로 표현할 수 있다.

이를 통해 본 프로젝트는 단순히 현재 PM2.5 값을 보여주는 것이 아니라, 실내 공간 전체의 오염 분포를 시각화하는 시스템으로 발전한다. 이는 상용 공기청정기 앱의 공기질 표시 기능과 로봇 지도 기반 관제 기능을 결합한 형태라고 볼 수 있다.

## 6. 차별화 기능 2: Utility 기반 고농도 구역 우선 정화

기존 순회형 로봇은 정해진 경로를 반복하거나 단순히 현재 위치 주변의 오염만 감지한다. 본 프로젝트는 로봇이 수집한 공기질 데이터를 기반으로 다음 정화 목표를 계산한다.

후보 위치별 Utility 점수는 다음과 같이 설계할 수 있다.

```text
Utility = 오염도 점수 - 이동 거리 비용 - 최근 방문 패널티 + 미탐색 구역 보너스
```

각 항목은 다음 의미를 가진다.

| 항목 | 의미 |
| --- | --- |
| 오염도 점수 | PM2.5 농도가 높을수록 증가 |
| 이동 거리 비용 | 현재 로봇 위치에서 멀수록 감소 |
| 최근 방문 패널티 | 최근에 이미 정화한 구역이면 감소 |
| 미탐색 구역 보너스 | 아직 충분히 측정하지 않은 구역이면 증가 |

이 구조를 적용하면 로봇은 정해진 순서대로 움직이는 것이 아니라, 실시간 공기질 정보와 이동 비용을 함께 고려하여 정화 우선순위를 결정한다. 웹 UI에는 선택된 다음 목표 지점과 Utility 점수를 함께 표시하여, 로봇이 왜 그 위치로 이동하는지 설명할 수 있다.

## 7. 차별화 기능 3: 정화 전후 효과 시각화

정화 기능의 실효성을 보여주기 위해, 로봇이 고농도 구역에 도착했을 때 정화 전 PM2.5 값과 일정 시간 정화 후 PM2.5 값을 비교한다.

예시는 다음과 같다.

```text
Before: 72 ug/m3
After: 41 ug/m3
Reduction: -43%
```

이 정보는 웹 대시보드의 지도 또는 상태 패널에 표시한다. 이를 통해 단순히 팬이 작동했다는 사실을 보여주는 것을 넘어, 실제 정화 효과를 수치로 검증하는 구조를 만들 수 있다.

## 8. 현재까지 진행상황

현재 프로젝트는 다음 단계까지 진행되어 있다.

### 8.1 시스템 환경 구성

- 노트북 환경: Ubuntu 24.04, ROS 2 Jazzy
- TurtleBot3 Raspberry Pi 환경: Ubuntu Server 24.04, ROS 2 Jazzy
- 네트워크: iPhone 개인 핫스팟 기반 `172.20.10.x` 대역
- 노트북 IP: `172.20.10.5`
- TurtleBot3 IP: `172.20.10.2`
- ROS_DOMAIN_ID: `30`

### 8.2 로봇 및 ROS 기능

- TurtleBot3 Waffle 기반 주행 환경 구성
- ROS 2 Jazzy 기반 TurtleBot3 bringup 사용
- Navigation2 기반 저장 맵 주행 구조 구성
- Cartographer 및 라이다 기반 지도 작성 실험 구조 준비
- `/scan_filtered` 기반 라이다 근거리 노이즈 제거 구조 포함

### 8.3 센서 및 하드웨어 제어

- PMS7003 미세먼지 센서 연동 노드 작성
- PMS7003 시리얼 프레임 헤더 `0x42 0x4d`를 추적하여 PM2.5 값 파싱
- PM2.5 값을 ROS 토픽 `/pms7003/pm25`로 발행
- 릴레이 제어 노드를 통해 블로우팬 ON/OFF 제어 구조 구성
- 팬은 Raspberry Pi에서 직접 구동하지 않고 외부 12V 전원과 릴레이를 통해 제어하는 구조로 설계

### 8.4 공기정화 FSM

`real_cleaner.py`에는 실전 관제용 공기정화 FSM이 작성되어 있다.

- `/pms7003/pm25` 구독
- `/robot_mode` 구독을 통한 수동/자동 모드 전환
- PM2.5 값이 오염 기준 이상이면 로봇 정지 및 팬 작동
- PM2.5 값이 청정 기준 이하로 내려가면 팬 정지
- 자동 모드에서 수동 모드로 전환될 때 잔여 주행 명령을 초기화하여 즉시 정지

현재 설정값은 다음과 같다.

```text
오염 감지 기준: PM2.5 >= 100
정화 완료 기준: PM2.5 <= 45
```

### 8.5 웹 관제 대시보드

- rosbridge websocket 기반 웹 UI 구성
- iPad 또는 브라우저에서 수동 조종 가능
- 자동/수동 모드 전환 가능
- 현재 PM2.5 값, 팬 상태, 로봇 상태 표시 구조 포함
- `/map_web` 토픽을 통한 웹 지도 표시 구조 작성
- `/robot_pose_web` 토픽을 통한 웹용 로봇 위치 표시 구조 작성
- 향후 Heatmap, Utility 목표 표시, 정화 전후 효과 표시를 추가할 기반이 마련됨

### 8.6 실행 자동화

- Raspberry Pi 실행 자동화 스크립트 `start_raspberry_pi.sh` 작성
- 노트북 실행 자동화 스크립트 `start_laptop.sh` 작성
- 통합 시연용 `run_demo.sh` 구성
- 실행 로그를 `logs/` 디렉터리에 저장하는 구조 포함

| 본 프로젝트 | TurtleBot3, PMS7003, Nav2, 웹 UI, 릴레이 팬 | 현재 Heatmap/Utility 기능은 추가 구현 필요 | 공기질 디지털 트윈과 자율 정화 의사결정 구조를 직접 설계 |

## 10. 최종 차별성 문장

본 프로젝트의 최종 차별성은 다음과 같이 표현할 수 있다.

> 기존 공기청정기는 장치 주변의 공기질을 측정하고 정화하는 데 초점이 있지만, 본 프로젝트는 로봇이 실내 공간을 이동하며 위치별 PM2.5 데이터를 수집하고, 이를 디지털 트윈 지도 위에 Heatmap으로 시각화하며, Utility 기반 알고리즘을 통해 고농도 구역을 우선 정화하는 자율 공기질 관리 시스템이다.

또는 발표용으로 더 간결하게 다음과 같이 표현할 수 있다.

> 본 프로젝트는 "이동형 공기청정기"가 아니라, 실내 공기질을 지도화하고 스스로 정화 우선순위를 결정하는 ROS 2 기반 디지털 트윈 공기질 관리 로봇이다.

## 11. 향후 구현 계획

향후 구현은 다음 순서로 진행하는 것이 적절하다.

1. 웹 지도 디자인을 발표용 하이브리드 맵 형태로 개선
2. 로봇 위치와 PM2.5 값을 결합한 측정점 표시
3. 측정점 기반 Heatmap overlay 구현
4. 고농도 후보 구역 자동 선택
5. Utility 점수와 다음 정화 목표 표시
6. 정화 전후 PM2.5 변화율 표시

이 순서로 구현하면 중간 단계에서도 시각적으로 확인 가능한 결과물을 만들 수 있으며, 최종적으로는 공기질 지도 생성, 자율 정화 판단, 정화 효과 검증이 하나의 대시보드에서 연결되는 형태의 차별화된 시스템을 완성할 수 있다.
