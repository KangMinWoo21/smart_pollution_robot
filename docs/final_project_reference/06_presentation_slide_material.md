# 최종 발표 PPT 제작용 슬라이드 자료

이 문서는 윈도우에서 PPT를 만들 때 바로 옮겨 쓸 수 있는 슬라이드별 문구와 발표 참고 대본입니다. 기존 `캡스톤디자인_발표_강민우김희수.pptx`의 흐름을 기준으로 정리했습니다.

## 1. 표지

제목:

```text
자율주행 스마트 공기청정 로봇
```

부제:

```text
ROS 2 + SLAM 기반 실시간 오염 판단 및 우선순위 정화 시스템
```

발표 대본:

> 저희 프로젝트는 실내 공기질을 단순히 측정하는 것을 넘어, 로봇이 오염 가능성이 높은 위치를 직접 찾아가고 팬을 작동해 정화까지 수행하는 자율주행 스마트 공기청정 로봇입니다.

## 2. 연구 배경

핵심 문구:

- 고정형 공기청정기는 공간 사각지대가 발생합니다.
- 랜덤 이동형 공기청정기는 급한 오염 위치를 우선 처리하기 어렵습니다.
- 기존 제품은 공기질 수치 표시와 실제 이동 정화가 분리되어 있습니다.

발표 대본:

> 기존 공기청정기는 설치 위치 주변은 잘 정화하지만, 방 구조와 가구 배치에 따라 정화 편차가 생깁니다. 이동형 제품도 단순 순회나 랜덤 주행에 가까워 실제 오염이 심한 위치를 먼저 처리하기 어렵습니다.

## 3. 기존 제품과의 차별성

핵심 문구:

- 오염 기반 우선순위 이동
- PM2.5 변화량과 LiDAR 후보 기반 판단
- Web UI 기반 집중 정화 구역 선택
- 릴레이와 팬을 통한 실제 정화 동작

발표 대본:

> 저희 시스템은 공기질을 표시하는 데서 끝나지 않고, 오염 가능성이 높은 위치로 이동해 현장 측정을 수행하고, 오염원으로 확정되면 실제 팬을 작동합니다.

## 4. 연구 목표

핵심 문구:

- SLAM 기반 실내 지도 활용
- Nav2 기반 자율 이동
- PMS7003 기반 PM2.5 실시간 측정
- LiDAR 후보와 현장 측정을 결합한 오염원 판단
- 팬 정화까지 이어지는 통합 동작

발표 대본:

> 목표는 실내 지도를 기반으로 로봇이 이동하고, 미세먼지 센서와 LiDAR 정보를 함께 사용해 오염 가능성이 높은 위치를 판단한 뒤, 팬 정화까지 수행하는 통합 시스템을 구현하는 것입니다.

## 5. 데모 시나리오

슬라이드 문구:

```text
1. 수동 모드: 조이스틱 주행 및 팬 ON/OFF 확인
2. 자동 모드: 정화 후보 지점 탐색
3. 주방 집중: 주방 주변 후보 지점 우선 방문
4. 현장 측정: PM2.5 변화량 확인
5. 오염원 확정: LiDAR 후보와 측정값 기반 판단
6. 팬 정화: 정화 방향 정렬 후 팬 작동
```

발표 대본:

> 시연에서는 먼저 수동 제어와 팬 제어를 확인하고, 이후 자동 모드에서 주방 집중 정화를 선택합니다. 로봇은 주방 주변 후보 지점을 우선 방문하고, 센서 기반 판단 후 팬 정화까지 수행합니다.

## 6. 전체 시스템 구성도

슬라이드 구성:

- 왼쪽: Web UI
- 가운데: 노트북 ROS 2 시스템
- 오른쪽: TurtleBot3 Raspberry Pi
- 아래: 주요 토픽 흐름

넣을 토픽:

```text
/robot_mode
/target_zone
/pms7003/pm25
/scan
/odom
/hardware/relay
/map_web
/robot_pose_web
```

발표 대본:

> Web UI에서 사용자가 모드와 집중 정화 구역을 선택하면, rosbridge를 통해 ROS 토픽으로 전달됩니다. 노트북의 자동 정화 노드는 Nav2 목표를 생성하고, Pi에서는 센서와 릴레이 제어가 실제 하드웨어와 연결됩니다.

## 7. 주방 집중 정화 기능

슬라이드 제목:

```text
주방 집중 정화 기능
```

부제:

```text
생활 오염 구역을 우선 관리하는 집중 정화 기능
```

핵심 문구:

- 주방은 조리, 연기, 냄새, 미세먼지가 자주 발생하는 구역입니다.
- 사용자가 `주방 집중`을 선택하면 주방 주변 정화 후보 지점을 우선 탐색합니다.
- PM2.5 변화량과 LiDAR 후보 정보를 함께 확인합니다.
- 현장 측정 후 오염원으로 확정되면 팬 정화를 수행합니다.

흐름도:

```text
주방 집중 선택 → 주방 정화 후보 지점 우선 탐색 → PM2.5 변화 감지
→ LiDAR 오염 후보 확인 → 현장 측정 → 오염원 확정
→ 정화 방향 정렬 → 팬 정화
```

발표 대본:

> 주방 집중 정화는 전체 프로젝트의 핵심 기능 중 하나입니다. 주방은 조리 과정에서 미세먼지와 냄새가 자주 발생하는 공간이므로, 전체 공간을 동일하게 순찰하기보다 주방 주변 정화 후보 지점을 먼저 방문하도록 했습니다. 이동 중 PM2.5 변화와 LiDAR 후보 정보를 확인하고, 현장 측정으로 오염원을 확정한 뒤 팬을 작동합니다.

## 8. 하드웨어 시스템

핵심 문구:

- TurtleBot3 Waffle 기반 모바일 플랫폼
- LDS-02 LiDAR로 지도 작성과 장애물 감지
- PMS7003으로 실내 PM2.5 측정
- Raspberry Pi GPIO와 릴레이로 12V 팬 제어
- HEPA 필터와 블로워 팬 기반 정화 모듈

발표 대본:

> 하드웨어는 TurtleBot3 Waffle을 기반으로 구성했고, PMS7003 센서와 릴레이 팬 모듈을 추가했습니다. 팬은 별도 12V 전원으로 구동하고, Raspberry Pi는 릴레이만 제어해 안정성을 확보했습니다.

## 9. 소프트웨어 시스템

핵심 문구:

- ROS 2 Jazzy 기반
- Zenoh RMW로 노트북과 Pi 통신
- Nav2로 목표 이동
- rosbridge와 roslibjs로 Web UI 연동
- 자동 정화 알고리즘은 `real_cleaner.py`, 판단 로직은 `cleaning_logic.py`

발표 대본:

> 소프트웨어는 ROS 2 Jazzy를 기반으로 하고, 노트북과 Pi는 Zenoh로 통신합니다. Web UI는 rosbridge를 통해 ROS 토픽을 발행하고, 자동 정화 노드는 Nav2와 센서 토픽을 이용해 이동과 정화를 제어합니다.

## 10. 핵심 알고리즘 1: 정화 후보 지점 기반 탐색

핵심 문구:

- 지도 위 이동 가능한 정화 후보 지점 정의
- Nav2로 후보 지점 순차 이동
- 구역 선택 시 후보 지점을 필터링
- 발견된 오염원 주변은 다시 탐색하지 않도록 무시 반경 적용

발표 대본:

> 로봇은 아무 곳이나 무작위로 이동하지 않고, 지도 위에서 안전하게 이동 가능한 정화 후보 지점을 기반으로 탐색합니다. 주방 집중처럼 구역이 선택되면 해당 구역 후보를 우선 방문합니다.

## 11. 핵심 알고리즘 2: PM2.5 + LiDAR 기반 판단

핵심 문구:

- PM2.5 비정상값 제거
- 최근 기준선 대비 상승량 확인
- LiDAR 원형 후보 감지
- 현장 측정 평균으로 오염 가능성 판단
- 오염원 확정 후 정화 방향 정렬

발표 대본:

> 자동 정화 알고리즘은 PM2.5 절댓값만 보지 않고 최근 기준선 대비 상승량을 봅니다. 여기에 LiDAR 후보 정보를 함께 사용해 오염 가능성이 높은 위치를 좁히고, 현장 측정 후 오염원을 확정합니다.

## 12. 핵심 기능: 야간 모드 설명 연결

기존 PPT의 야간 모드 슬라이드를 유지할 경우 사용할 문구:

- 야간에는 이동 소음과 불필요한 주행을 줄이는 방향으로 확장 가능
- 속도 제한, LED/부저 OFF, 필요 시 짧은 이동 전략
- 오염 심각도가 높은 경우에만 최소 이동으로 정화

발표 대본:

> 야간 모드는 현재 자동 정화 구조를 사용자 생활 환경에 맞게 확장하는 기능입니다. 속도와 이동 빈도를 줄이고, 필요한 경우에만 짧게 이동하도록 설계할 수 있습니다.
