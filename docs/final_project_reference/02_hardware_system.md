# 하드웨어 시스템

PPT 제작 시 `하드웨어 시스템`, `부품 구성`, `시스템 구성 설명` 슬라이드에 사용하기 좋은 내용입니다.

## 전체 하드웨어 구조

로봇 플랫폼은 TurtleBot3 Waffle을 기반으로 구성했습니다. TurtleBot3는 LiDAR, 모터, OpenCR 제어 보드, Raspberry Pi 연동 구조가 준비되어 있어 SLAM과 Nav2 자율주행 실험에 적합합니다.

공기청정 기능을 위해 PMS7003 미세먼지 센서, 릴레이 모듈, 12V 블로워 팬, HEPA 필터 기반 정화 모듈을 추가했습니다.

## 주요 부품

| 구분 | 부품 | 역할 |
| --- | --- | --- |
| 모바일 플랫폼 | TurtleBot3 Waffle | 자율주행 로봇 베이스 |
| 메인 컨트롤러 | Raspberry Pi 4B | ROS 노드, 센서, 릴레이 제어 |
| 모터 제어 | OpenCR 1.0, Dynamixel XL430 | 좌우 바퀴 구동 |
| 거리 센서 | LDS-02 LiDAR | SLAM, 장애물 감지, 원형 후보 감지 |
| 미세먼지 센서 | PMS7003 | PM2.5 실시간 측정 |
| 정화 모듈 | 12V 팬 + HEPA 필터 | 오염원 주변 공기 정화 |
| 팬 제어 | 릴레이 모듈 | ROS 명령을 실제 팬 ON/OFF로 변환 |
| 전원 | 11.1V 배터리 및 전원 분배 | 구동부와 정화 모듈 전원 공급 |

## PMS7003 미세먼지 센서

- Raspberry Pi UART를 통해 PM2.5 값을 읽습니다.
- 현재 시연 설정에서는 `PMS_PORT=/dev/ttyS0`를 사용합니다.
- `/dev/ttyS0`는 기본적으로 `serial-getty@ttyS0.service`가 잡고 있을 수 있으므로, 시연 전 해당 서비스를 멈춥니다.
- 센서 노드는 `/pms7003/pm25` 토픽으로 PM2.5 값을 발행합니다.

발표 문장:

> PMS7003 센서로 실내 PM2.5 값을 실시간 수집하고, ROS 토픽으로 발행해 자동 정화 알고리즘의 입력으로 사용했습니다.

## LiDAR

- TurtleBot3의 LDS-02 LiDAR를 사용합니다.
- 기본 역할은 SLAM 지도 작성, 위치 추정, 장애물 감지입니다.
- 자동 정화 알고리즘에서는 가까운 원형 장애물 후보를 감지해 오염 후보 판단에 참고합니다.

발표 문장:

> LiDAR는 지도 작성과 장애물 회피뿐 아니라, 로봇 주변의 원형 후보를 감지해 오염원 후보를 좁히는 데도 활용했습니다.

## 릴레이와 팬

- 릴레이 제어 노드는 `/hardware/relay` 토픽을 구독합니다.
- `true` 메시지를 받으면 릴레이 ON, `false` 메시지를 받으면 릴레이 OFF로 동작합니다.
- 릴레이는 Raspberry Pi의 physical pin 12를 사용합니다.
- GPIO 접근에는 root 권한이 필요합니다.

발표 문장:

> ROS에서 발행한 팬 제어 명령이 Raspberry Pi의 릴레이 제어 노드로 전달되고, 릴레이가 12V 팬 전원을 스위칭해 실제 정화 동작을 수행합니다.

## 전원 구성

- Raspberry Pi와 센서 계통은 안정적인 5V 전원이 필요합니다.
- 팬은 전류 소모가 크므로 Raspberry Pi 전원에서 직접 구동하지 않고 별도 12V 전원을 릴레이로 제어합니다.
- 제어부와 구동부 전원을 분리해 팬 동작 시 로봇 제어부가 불안정해지는 문제를 줄입니다.

## 하드웨어 발표 핵심

- TurtleBot3 Waffle을 기반으로 자율주행과 정화 모듈을 결합했습니다.
- PMS7003과 LiDAR를 함께 사용해 오염 판단 입력을 구성했습니다.
- 릴레이와 팬을 통해 소프트웨어 판단이 실제 정화 동작으로 이어지도록 했습니다.
