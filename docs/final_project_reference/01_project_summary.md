# 프로젝트 개요와 발표 핵심 메시지

PPT 제작 시 `연구 배경`, `기존 제품과의 차별성`, `연구 목표`, `결론` 슬라이드에 사용하기 좋은 내용입니다.

## 프로젝트명

자율주행 스마트 공기청정 로봇

## 한 문장 요약

ROS 2와 SLAM 기반 자율주행, PM2.5 센서, LiDAR 후보 판단, 웹 관제 UI, 팬 제어를 결합해 오염 가능성이 높은 공간을 우선적으로 찾아가 정화하는 이동형 공기청정 로봇입니다.

## 문제 정의

- 고정형 공기청정기는 설치 위치 주변만 강하게 정화하고, 방 구조나 가구 배치에 따라 공기 정화 사각지대가 생깁니다.
- 단순 이동형 공기청정기는 랜덤 주행이나 단순 순회에 의존해 실제 오염이 심한 위치를 우선 처리하기 어렵습니다.
- 일반 공기질 모니터링 제품은 수치를 보여주지만, 오염 위치로 이동해 직접 정화하는 행동까지 연결되지 않습니다.
- 주방처럼 생활 패턴상 오염이 자주 발생하는 구역은 전체 공간과 같은 우선순위로 다루면 대응이 늦어질 수 있습니다.

## 개발 목표

- 실내 지도를 기반으로 로봇이 이동 가능한 공간을 이해합니다.
- PM2.5 센서로 실시간 미세먼지 변화를 수집합니다.
- 오염 가능성이 높은 정화 후보 지점을 우선 탐색합니다.
- LiDAR 후보 정보와 현장 측정을 함께 사용해 오염원을 판단합니다.
- 오염원으로 확정되면 정화 방향을 맞추고 팬을 작동합니다.
- 웹 UI에서 수동 주행, 팬 제어, 자동 정화, 주방 집중 정화를 제어합니다.

## 핵심 차별성

### 오염 기반 우선순위 이동

단순히 공간을 순서대로 도는 것이 아니라, 미세먼지 변화량과 후보 지점 정보를 바탕으로 정화 가치가 높은 지점을 먼저 방문합니다.

### 구역 집중 정화

사용자가 `주방 집중`을 선택하면 로봇은 전체 공간보다 주방 주변 정화 후보 지점을 우선적으로 탐색합니다. 주방은 조리, 연기, 냄새, 미세먼지가 자주 발생하는 생활 오염 집중 구역이므로 실제 사용 상황과 연결된 기능입니다.

### 센서 기반 오염원 판단

PM2.5 수치만 보고 바로 팬을 켜지 않고, 이동 중 변화량, LiDAR 후보, 현장 측정을 함께 확인해 오염 가능성이 높은 위치를 판단합니다.

### 웹 관제와 실제 하드웨어 제어 연결

웹 UI의 모드 선택과 집중 정화 구역 선택이 ROS 토픽으로 전달되고, 로봇 이동, 센서 판단, 릴레이 팬 제어까지 하나의 흐름으로 연결됩니다.

## 발표에서 강조할 가치

- `창의성`: 생활 패턴상 오염 가능성이 높은 주방을 우선 관리하는 구역 집중 정화 기능
- `기술성`: ROS 2, Nav2, Zenoh, LiDAR, PM2.5 센서, Web UI, GPIO 릴레이 제어 통합
- `동작상태`: 웹 버튼 입력부터 로봇 이동, 오염원 확인, 팬 정화까지 이어지는 시연 가능 흐름

## 최종 결론 문장

본 프로젝트는 미세먼지 수치를 단순 표시하는 것을 넘어, 자율주행 로봇이 오염 가능성이 높은 구역을 직접 찾아가고, 센서 기반으로 판단한 뒤 실제 팬 정화까지 수행하는 통합형 스마트 공기청정 시스템입니다.
