# 핵심 알고리즘

PPT 제작 시 `핵심 알고리즘`, `주방 집중 정화 기능`, `데모 시나리오`, `검증 결과` 슬라이드에 사용하기 좋은 내용입니다.

## 전체 자동 정화 흐름

```text
자동 모드 선택
    ↓
집중 정화 구역 선택
    ↓
정화 후보 지점 탐색
    ↓
Nav2 목표 이동
    ↓
PM2.5 현장 측정
    ↓
PM2.5 변화량 + LiDAR 후보 확인
    ↓
오염원 확정
    ↓
정화 방향 정렬
    ↓
팬 정화
    ↓
정화 완료 및 상태 갱신
```

## 자동 정화 FSM

자동 정화 알고리즘은 명시적인 상태 문자열보다 다음 동작 흐름으로 상태를 관리합니다.

| 상태 | 의미 | 다음 동작 |
| --- | --- | --- |
| 대기/수동 | 사용자가 직접 조이스틱과 팬을 제어 | 자동 모드 선택 시 탐색 시작 |
| 탐색 | 정화 후보 지점으로 Nav2 목표 이동 | 도착 후 현장 측정 |
| 현장 측정 | 일정 시간 PM2.5 평균 측정 | 변화량이 크면 추적 또는 확정 |
| 추적 | 후보 주변의 인접 지점 측정 | 더 높은 지점이 있으면 갱신, 아니면 확정 |
| 오염원 확정 | 가장 가능성 높은 위치 결정 | 정화 방향 정렬 |
| 팬 정화 | 팬을 켜고 일정 시간 정화 | 정화 완료 후 팬 OFF |
| 복귀 | 시연 조건에 따라 출발 지점으로 복귀 | 수동 대기 |

## 정화 후보 지점 기반 탐색

로봇은 지도 위에 미리 정의된 정화 후보 지점을 순서대로 방문합니다. 각 후보 지점은 `(x, y, yaw)` 형태의 지도 좌표이며, 발표에서는 개발 용어인 `waypoint` 대신 `정화 후보 지점`이라고 설명합니다.

기본 시연 후보 지점:

```text
3.07, 4.98, -1.59
5.18, 1.62,  0.05
8.00, 1.40,  1.47
7.50, 5.19, -2.90
5.42, 4.68,  3.01
```

## 주방 집중 정화 기능

주방 집중 정화는 전체 프로젝트 안의 대표 기능 사례입니다.

### 문제

주방은 조리 과정에서 연기, 냄새, 미세먼지가 자주 발생하는 생활 오염 집중 구역입니다.

### 해결

사용자가 Web UI에서 `주방 집중`을 선택하면 로봇은 전체 공간보다 주방 주변 정화 후보 지점을 우선적으로 탐색합니다.

### 판단

이동 중 PM2.5 변화량과 LiDAR 후보 정보를 함께 확인하고, 현장 측정으로 오염 가능성이 높은 위치를 판단합니다.

### 동작

오염원으로 확정되면 로봇이 정화 방향을 맞춘 뒤 팬을 작동합니다.

흐름도:

```text
주방 집중 선택
    ↓
주방 정화 후보 지점 우선 탐색
    ↓
PM2.5 변화 감지
    ↓
LiDAR 오염 후보 확인
    ↓
현장 측정
    ↓
오염원 확정
    ↓
정화 방향 정렬
    ↓
팬 정화
```

## PM2.5 변화량 판단

자동 정화 알고리즘은 PM2.5 절댓값만 보지 않고 최근 기준선 대비 상승량을 확인합니다.

- 비정상 센서값은 무시합니다.
- 최근 값 또는 평상시 기준선을 기준으로 삼습니다.
- 기준선보다 일정량 이상 상승하면 오염 후보로 판단합니다.
- 외부 미세먼지가 나쁠 때는 실내 판단 기준을 조금 낮춥니다.

발표 문장:

> 단순히 PM2.5 값이 높다는 이유만으로 팬을 켜지 않고, 최근 기준선 대비 변화량을 확인해 실제 오염 발생 가능성을 판단했습니다.

## LiDAR 후보 판단

LiDAR는 로봇 주변의 가까운 원형 후보를 탐지하는 데 사용됩니다.

- LiDAR scan에서 일정 거리 안의 점들을 cluster로 묶습니다.
- cluster의 폭이 목표 지름과 비슷한지 확인합니다.
- 최근 감지된 후보가 있을 때 PM2.5 상승과 함께 추적 모드로 전환합니다.
- 추적 중에는 LiDAR 후보 방향을 바라보는 측정 목표를 만들어 오염원 확정에 사용합니다.

발표 문장:

> LiDAR를 장애물 회피에만 쓰지 않고, 오염원으로 의심되는 물체 후보를 찾는 보조 판단 정보로 활용했습니다.

## 현장 측정과 오염원 확정

정화 후보 지점에 도착하면 일정 시간 동안 PM2.5 평균을 측정합니다.

- 현장 측정 시간은 시연 설정에서 기본 2초입니다.
- 측정 평균이 기준선보다 높으면 주변 후보를 추가 확인합니다.
- 추적 후보를 모두 확인하면 가장 높은 측정 위치를 오염원으로 확정합니다.
- 시연 안정성을 위해 특정 경로에서는 준비된 목표 지점 도착 시 오염원 확정 흐름을 사용합니다.

발표 문장:

> 로봇은 후보 지점에 도착한 뒤 바로 결론을 내리지 않고, 짧은 현장 측정으로 실제 PM2.5 변화를 확인한 후 오염원을 확정합니다.

## 정화 방향 정렬과 팬 정화

오염원으로 확정된 위치에 대해 로봇은 정화 방향을 맞춘 후 팬을 작동합니다.

- 확정 위치의 yaw를 180도 돌린 정렬 목표를 생성합니다.
- Nav2 정렬이 성공하면 팬을 켭니다.
- 정렬 실패나 Nav2 서버 부재 시에도 현재 위치에서 팬 정화로 fallback합니다.
- 팬은 기본 7초 동안 작동한 뒤 꺼집니다.

발표 문장:

> 오염원 위치를 찾은 뒤에는 단순히 멈추는 것이 아니라, 정화 방향을 맞추고 릴레이를 통해 팬을 작동시켜 실제 정화 동작까지 수행합니다.

## 알고리즘 발표 핵심

- 정화 후보 지점 기반으로 안전한 이동 목표를 사용합니다.
- PM2.5 변화량으로 오염 가능성을 판단합니다.
- LiDAR 후보 정보로 오염원 위치 판단을 보강합니다.
- 현장 측정으로 실제 오염 정도를 확인합니다.
- 오염원 확정 후 정화 방향 정렬과 팬 정화까지 연결합니다.
